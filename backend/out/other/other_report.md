# 第二所学校（A 学院）培养方案解析报告

## 0. 先给结论：这 8 份 PDF 里没有文字

| 检测项 | 结果 |
|---|---|
| 字体对象（/Font） | **0 个** |
| 文本操作符（BT / Tj / TJ） | **0 个** |
| 页面构成 | 纯矢量路径：表格线 + 字形轮廓（文字被"转曲"） |

**这不是"字段识别不出来"，是文件里根本没有字符。** 用 pypdf / pdfplumber / PyMuPDF 任何一个库去读，结果都会是空字符串——不是它们不行，是文件里没有可读的文本。

所以本仓库加了一级兜底：`pdf_raster.py` 自己解析内容流、把路径按奇偶规则填充，用 numpy + Pillow 栅格化成 1721×2434 的图，读出来和原表一致。生产环境里这一步换成 OCR 或视觉模型即可，接口位置是一样的。

**对产品的直接影响**：上传入口必须先做"有没有文字层"的探测。没有就走 转图 → OCR → 结构化。否则真实学校的文件，解析成功率是 0。

## 1. 两份数据的形态对照

| 维度 | 第一份（工学院·Word 培养方案） | 第二份（A 学院·教务导出 PDF） |
|---|---|---|
| 载体 | `.doc`，有文字层 | `.pdf`，矢量转曲，无文字层 |
| 组织方式 | 模块 → 课程组 → 课程，带"XX：N 学分"声明 | 8 个分文件，用【课程性质】列分组，**无学分声明** |
| 学期表示 | `1秋`、`3秋2春` | 整数 `1`~`11` |
| 类型列 | 一列（必修 / 工程模块 / 植物模块组） | **两列**（课程性质 + 课程属性），语义重叠 |
| 学生数据 | 无 | 有【完成情况】【已获学分】（18 条） |
| 总学分 | 150，可逐级核平 | 未声明，无法核平 |

## 2. 解析结果

| 课程组 | 门数 | 学分 |
|---|---|---|
| 专业必修 | 14 | 40.00 |
| 专业选修 | 22 | 39.00 |
| 大类平台课程I | 6 | 16.50 |
| 学院平台课 | 7 | 14.50 |
| 理学大类 | 4 | 16.00 |
| 工信大类 | 2 | 4.00 |
| 生命科学大类 | 1 | 2.00 |
| 生态大类 | 1 | 3.00 |
| **合计** | **57 门** | **135.00** |

**注意 135 不是毕业学分**。它只是"课程池"的累加：专业选修 22 门共 39 学分，学生只需从中选够要求的学分。把课程池当要求，是这类数据最容易犯的错。

18 条学籍记录（修读中/已修通过/已获学分）已剥离到独立的 `student_records`。

## 3. 这批文件暴露的 6 个问题

1. **学期码越界**：毕业实习、毕业论文标 `11`，企业实训标 `9`，超出四年制 1–8 学期。这个字段很可能不是"第几学期"而是教务系统的学期编码，必须让用户确认语义。
2. **总学时列混入"周"**：毕业实习 4、毕业论文 5、企业实训 2.5 —— 数量级明显是周数，不是学时。同一列两种口径。
3. **课程性质与课程属性冗余**：`专业必修 / 必修` 两列说的是同一件事，且属性列恒为必修或选修，没有信息量。
4. **变体写法**：出现一处 `专业选修课`，其余是 `专业选修`，不做归一就会多出一个假分组。
5. **学籍数据混入培养方案**：同一张表既有"这门课要求多少学分"，又有"这个学生修得怎么样"。这两个东西的生命周期完全不同，必须拆表。
6. **选修组不等于要求**：见上。

## 4. 对数据模型的结论

**schema 不用改就能装下这份数据**——`courses / groups / terms / credits / type` 全部对得上，57 门课一条不丢。要改的是三个地方：

| 需要明确的字段 | 为什么 |
|---|---|
| `term_code` | 数字学期（1–11）和"1秋"是两种编码，现在被硬塞进 `terms` 字符串数组 |
| `hours_unit` | 学时 / 周数混列，必须标明单位，否则学时统计全错 |
| `group.rule` | 这份导出没有 `all_of / credits / pick_n`，只能默认：必修组=`all_of`，选修组=课程池。规则缺失时必须显式标 `rule: unknown`，不能默默当成"全修" |

以及一条校验规则要改：**选修组的课程合并不参与学分核平**，只统计"池子大小"。

## 5. 复现

```bash
# 1) 检测有没有文字层
python pdf_adapter.py "<file>.pdf"        # 无输出 = 没有文字层

# 2) 无文字层则栅格化
python pdf_raster.py "<file>.pdf" out/render/p1.png 3.0

# 3) 识别后写入 CSV（生产环境换成 OCR/视觉模型）
#    见 out/other/courses.csv

# 4) 同一套 schema 装配
python assemble_course_list.py out/other/courses.csv out/other/other_curriculum.json
```
